# Data sources log

Every dataset we train or test on is listed here, with its licence and how we
mapped its labels onto ours. The report needs this table, and so does anyone
who wants to reproduce our numbers.

Our three labels: **legit** (normal messages and real bank alerts),
**suspicious** (unwanted or possibly harmful, but not clearly phishing),
**phishing** (tries to steal money, credentials or data).

## What we actually use

| Source | What it is | Rows kept | Language | Label mapping | Licence / consent |
|---|---|---|---|---|---|
| seed v1 (ours) | Hand-written examples using fictional banks | 36 | en / si / singlish | written with our labels | Not real data; written by us with AI help |
| synthetic v1 (ours) | 30 templates × 30 variations | 900 | en / si / singlish | written with our labels | Generated by us; **training only** |
| Smishtank (Timko & Rahman, 2024) | User-reported smishing | 1,091 | en | Account Alert, Delivery, Prize/Contest, Finance/Crypto, Lawsuits/Settlements, Loans/Credit → phishing. Advertisement, Job Advertisement, Wrong Number/Romance, Other → suspicious | Public research dataset |
| Mendeley smishing (Mishra & Soni, 2022) | SMS labelled ham / spam / smishing | 5,971 | en | ham → legit, spam → suspicious, smishing → phishing | Public research dataset |
| ExAIS SMS Spam (Abayomi-Alli et al., 2016) | Nigerian SMS spam corpus | 5,240 | en | HAM → legit, SPAM → suspicious | Public research dataset |
| UCI SMS Spam (Almeida et al., 2011) | The standard English SMS spam set | 5,574 | en | ham → legit, spam → suspicious | Public research dataset |
| Revised Indian dataset | Hindi / Telugu / code-mixed SMS | 4,565 | hi-mixed / te / te-roman | ham → legit, spam → suspicious | Public GitHub dataset |

After removing duplicates across sources (8,998 of them), the combined public
file holds **13,021 messages**: 8,844 legit, 3,139 suspicious, 1,038 phishing.

Where the public rows came out by language: 12,582 English, 237 romanised
Telugu, 107 Telugu script, 95 Hindi-mixed. **Zero Sinhala and zero Singlish** —
which is the whole reason our own data exists, and the reason we report results
on the local rows separately.

## Deliberately NOT used, and why

| Source | Why not |
|---|---|
| Combined-Labeled (84k) | Labels were produced by keyword matching, so they are unreliable |
| SMS Gateway, Spam Hunter, NUS corpus | No labels |
| Kor-Smishing | Korean; not one of our languages |
| Enron email spam | Email, not SMS |

## How to rebuild the combined file

```bash
python -m detection.get_datasets    # clones the two source repos into data/external/
pip install xlrd                    # only needed for the Indian .xls file
python -m detection.public_data     # writes data/processed/public_v1.csv
```

Without `xlrd`, convert the one Excel file first and the loader will pick up
the CSV automatically:

```bash
cd data/external/indian/Presentation
soffice --headless --convert-to csv --outdir . revisedindiandataset.xls
```

`data/external/` and `data/processed/` are both ignored by Git, because each
dataset carries its own licence and we must not redistribute them inside our
repository. Cite every one of them in the report.

## Rules

- Real or donated messages go in `data/real/` and are **never** committed.
- Remove names, phone numbers, account numbers and OTPs **before** saving any
  real message.
- Synthetic data is for training only. Final results must come from the real,
  hand-labelled gold test set.
- Any AI-generated data must be listed here **and** in the AI Use Disclosure
  appendix.
